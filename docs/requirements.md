# 需求说明

## 1. 背景

现有设备角色：

- Ubuntu 手机：长期在线、低功耗、Root、外接 SSD、Jellyfin 服务端。
- Windows / 其他手机：内容选择、网站登录和播放控制。
- 小米电视：通过 Wi-Fi 连接，只安装 Jellyfin Android TV 客户端并显示内容。

普通投屏经常丢失字幕，并要求每台电视客户端维护各网站登录状态。本项目希望把登录、解析和媒体流转换集中到服务器。

## 2. 产品目标

1. 控制设备通过浏览器完成操作，无需安装专用控制 App。
2. 电视只安装官方 Jellyfin 客户端。
3. 网站登录状态只保存在 Ubuntu 手机。
4. 支持将非 DRM 网页媒体转换为 Jellyfin 可播放的内容。
5. 优先转发或重新封装原始媒体，不默认重新编码。
6. 支持独立字幕，并允许电视端选择字幕轨道。
7. 本地流量走局域网，不依赖公网或 Tailscale 中继。

## 3. 非目标

- 绕过 DRM、付费授权、区域限制或网站访问控制。
- 把任意交互网页完整转换成低延迟远程桌面。
- 重新实现 Jellyfin 的媒体库、用户、播放器和转码系统。
- 为每个视频网站永久承诺兼容性。
- 将服务作为公网开放代理或多租户 SaaS。

## 4. 核心用户故事

### US-01 发送媒体到电视

用户在 Windows 或其他手机打开控制台，粘贴受支持网页 URL，选择“小米电视”，点击播放；电视的 Jellyfin 客户端开始播放。

### US-02 集中登录

需要登录的网站由服务器维护独立浏览器配置或 Cookie；电视不接触网站凭据。

### US-03 字幕播放

网关发现字幕后，将字幕标准化为 Jellyfin 支持的轨道。用户能在电视端选择、关闭或切换字幕。

### US-04 失败可解释

解析失败时，控制台明确区分：不支持的网站、登录失效、DRM、网络失败、媒体过期和转封装失败。

### US-05 远程控制

用户可在控制台查看播放状态，并执行播放、暂停、停止和进度跳转。能力取决于 Jellyfin 会话 API。

## 5. 功能需求

### FR-01 控制台

- 响应式 Web/PWA，支持 Windows 和手机浏览器。
- 显示 Jellyfin 播放设备及在线状态。
- 接收 URL、选择目标设备并展示解析进度。
- 保存常用站点入口，但不在浏览器本地保存网站密码。

### FR-02 URL 安全校验

- 默认只允许 HTTPS。
- 解析前后都执行 DNS/IP/redirect SSRF 校验。
- 禁止 loopback、链路本地、私网和云元数据地址；显式站点适配器除外。
- 限制响应体、重定向次数、解析时间和并发数。

### FR-03 媒体解析

- 首选站点适配器或 yt-dlp 提取元数据。
- 支持 HLS、DASH、MP4 及分离音视频轨道。
- 支持短期签名 URL、必要请求头及 Cookie 注入。
- 检测 DRM 或不支持的保护方式并拒绝处理。

### FR-04 字幕

- 发现 SRT、VTT、ASS/SSA 等字幕。
- 记录语言、默认、强制和听障标记。
- 必要时转换容器或字幕格式，不默认烧录字幕。

### FR-05 Jellyfin 集成

- 动态生成 M3U/M3U8，由 Jellyfin Live TV M3U Tuner 读取。
- 为当前播放任务提供稳定、短期授权的媒体 URL。
- 使用 Jellyfin API 获取设备与播放状态并发送控制指令。
- 电视只需要 Jellyfin 账号，不需要网站账号。

### FR-06 会话管理

- 每个站点使用隔离的服务器端会话。
- 登录失效时要求用户在控制台重新认证。
- Cookie 不写入日志、不返回电视、不暴露给 Jellyfin 客户端。

### FR-07 生命周期

- 播放任务支持创建、刷新、停止和过期清理。
- 短期媒体 URL 在播放期间按需刷新。
- 服务重启后不恢复正在播放的临时任务，但保留加密的站点会话。

## 6. 非功能需求

### 性能与功耗

- Direct Stream / Remux 是默认成功路径。
- 单用户场景下不因网关产生持续视频重新编码。
- 默认最多一个重型解析任务，防止手机过热。
- 本地播放启动目标：缓存命中 3 秒内，普通解析 10 秒内；站点响应时间不计入硬保证。

### 可用性

- Jellyfin 故障不破坏网关保存的网站会话。
- 网关故障不影响 Jellyfin 播放本地 NAS 内容。
- 每种失败返回稳定错误码和用户可执行建议。

### 兼容性

- 服务端首要目标：Ubuntu 24.04 ARM64。
- 显示端首要目标：Jellyfin Android TV 官方客户端。
- 控制端支持当前主流 Chromium 浏览器。

## 7. MVP 验收标准

1. 电视仅安装官方 Jellyfin 客户端即可播放网关频道。
2. 控制台能选择在线电视并发送一个公开、非 DRM 测试媒体。
3. 视频不重新编码，Jellyfin 日志显示 Direct Play 或 Remux。
4. 至少支持一个外挂字幕轨道并能在电视端切换。
5. 网站 Cookie 不出现在日志、M3U 或电视请求中。
6. 私网 URL、redirect 到私网和超限资源会被拒绝。
7. 网关停止后，本地 Jellyfin 媒体库仍正常工作。
